Cara Kerja Sistem

Encode

  • Pesan dienkripsi menggunakan AES
  • Ciphertext diubah menjadi biner
  • Bit pesan disisipkan ke pixel gambar menggunakan LSB
  • Gambar stego diunduh pengguna

Decode

  • Bit rahasia diambil dari gambar
  • Ciphertext diekstrak dari pixel
  • AES decrypt menggunakan password
  • Pesan asli ditampilkan
